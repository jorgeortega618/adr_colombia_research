# Colombian ADRs vs S&P 500 and USD/COP: Volatility, Dynamic Dependence, and Structural Breaks

## 📌 Project Overview & Current Analysis

This repository contains an end-to-end financial time-series pipeline analyzing the risk regimes and market integration of three major Colombian American Depositary Receipts (ADRs) trading on the NYSE: **Ecopetrol (EC)**, **Grupo Aval (AVAL)**, and **Bancolombia (CIB)**.

The analysis is structured around evaluating continuous daily data (10 trading years: Feb 2016 – Jan 2026) against two major macroeconomic factors:
1. The **S&P 500 Index (`^GSPC`)** 
2. The **USD/COP Exchange Rate (`COP=X`)**

### Current Empirical Pipeline (`adr_colombia_2026.ipynb`)
1. **Data Ingestion & Distribution Testing:** Calculation of stationary log returns (confirmed via ADF tests) and empirical moments for EC, AVAL, CIB, S&P 500, and USD/COP.
2. **Conditional Volatility Modeling:** Rigorous estimation of baseline risk using univariate ARX-GARCH models. Specifically, it tests symmetric `GARCH(1,1)` alongside asymmetric `EGARCH(1,1)` and `GJR-GARCH(1,1)` specifications using a Student's $t$ error distribution. Both the S&P 500 and the exchange rate are parameterized as exogenous regressors in the mean equation.
3. **Model Selection & Adequacy:** Goodness-of-fit evaluated via Bayesian Information Criterion (BIC), supported by post-estimation Ljung-Box and ARCH-LM residual diagnostics.
4. **Time-Varying Beta & Break Detection:** Observation of shifting systemic risk profiles via 252-day (1-year) rolling regressions and rolling correlations, coupled with endogenous identification of multiple breakpoint epochs using the PELT (Pruned Exact Linear Time) algorithm.
